기초 페르시아어 학습 포털

대면 강의 진도에 맞춘 실시간 랩(Lab) 세션 전용 공간

교재 연동 학습 도구
필수 어휘

기초 단어장

주차별 교재 진도에 등장하는 핵심 단어들을 객관식 서바이벌과 매칭 게임으로 확실하게 암기합니다.
핵심 규칙

문법 학습

교수님이 설명하신 문법 공식과 변화 규칙을 직관적인 퀴즈 형태로 빠르고 정확하게 체화합니다.
구조 체화

문장 조립

배운 단어와 문법을 활용하여, 페르시아어 어순에 맞게 텍스트 블록을 직접 조립하고 발화합니다.
주의 사항

본 페이지는 실제 오프라인 강의(Lab 세션)와 연동되어 진행되는 공간입니다.
우측 상단의 반(A1/A2) 설정이 본인의 실제 수강 과목과 일치하는지 반드시 확인한 후 학습 도구에 입장해 주십시오.
